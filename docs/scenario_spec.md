### R-01 분할입금

근거: 특금법 제4조의2 / 시행령 제8조의2 제1항

베이스라인: 1거래일 합산액 >= 기준액 (법정 기준 그대로)
탐지 조건: 위 + 단건 전부 기준액 미만 + 근접거래(기준액 50% 이상) 2건 이상

파라미터 조정 이력
- 초기 min_count=3에서 탐지 0건
- 원인: 계좌당 일일 현금거래가 1건(94%) 또는 2건(6%)으로 생성되어
  3건 이상 분할 패턴이 데이터에 부재
- min_count를 2로 조정 (2건 이상도 분할에 해당하며, 3은 근거 없는 잠정치였음)

결과: 44,362 → 56건 (99.9% 감축), 진성 포착 0건

진성 0건에 대하여: 본 데이터의 자금세탁 라벨은 전부 이체 기반
그래프 패턴(CYCLE·FAN-IN 등)에 부여되어 현금 분할입금 시나리오가
존재하지 않음. 이 결과 자체가 금액 기준 단독의 한계를 보여주는
근거이며, 패턴 기반 룰의 필요성을 뒷받침함.
